# java-calculator-precourse
## 요구사항
- [x] 쉼표(,), 콜론(:)을 구분자로 가지는 문자열을 분리할 수 있다.
  - 구분자는 특수문자이다.
  - [x] 쉼표(,), 콜론(:)을 제외한 구분자로 구분할 수 없다.
  - [x] 구분자가 없는 문자열에 대해서 예외가 발생한다.
  - [x] 구분자는 맨 앞에 올 수 없다.
  - [x] 구분자는 연속해서 올 수 없다.
- [x] 분리한 각 숫자들의 합을 반환할 수 있다.
  - [x] 숫자가 아닌 값에 대해서 예외가 발생한다.
  - [x] 숫자는 양수로만 이루어져야한다.
  - [x] 숫자는 Unsigned Long 타입의 범위여야 한다.
- [ ] 커스텀 구분자를 지정할 수 있다.
- [ ] 커스텀 구분자를 가지는 문자열을 분리할 수 있다.
  - 커스텀 구분자는 문자열 앞부분 '//'와 '\n' 사이에 위치하는 문자이다.
